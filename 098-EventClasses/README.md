# 098 — Event Classes

> 📦 **Phase 10 — Event Handling**

## 🎯 What is it?
When an event occurs, an **Event Object** is created. This object contains data about what just happened (e.g., which button was clicked, or what key was pressed).
These classes are found in the `java.awt.event` package.

## 📦 Key Event Classes

All event classes inherit from `java.util.EventObject`.

1. **`ActionEvent`**: Generated by button clicks or pressing Enter in a text field.
   - Useful method: `e.getSource()` (returns the object that fired the event), `e.getActionCommand()` (returns the text of the button).
2. **`MouseEvent`**: Generated by mouse interactions.
   - Useful methods: `e.getX()`, `e.getY()` (gets coordinates of the click).
3. **`KeyEvent`**: Generated by keyboard input.
   - Useful methods: `e.getKeyChar()`, `e.getKeyCode()`.
4. **`ItemEvent`**: Generated when a checkbox or dropdown selection changes.
5. **`WindowEvent`**: Generated by window status changes (closing, opening).

## 💻 Concept Example

```java
// Inside a listener method:
public void actionPerformed(ActionEvent e) {
    // Determine WHICH component fired the event
    Object source = e.getSource();
    
    // Determine the text command associated with the event
    String command = e.getActionCommand(); 
}
```

## 📝 Exam Tips
- `java.util.EventObject` is the root class for all events.
- `getSource()` is the most important method—it tells you exactly which UI component triggered the event.
